# MFK v1.2 — Kitchen Assistant

## Cooking Session
- One-tap launch from Today
- Uses planned servings automatically
- Full-screen step-by-step Cook Mode
- Progress bar and Previous/Next controls
- Screen Wake Lock
- Portrait lock where supported
- Resume interrupted cooking from Today
- Scaled ingredient drawer
- Automatic timer suggestions from method steps
- Active timer, vibration and alert
- Dinner-ready finish screen

## Cooking Journal
- Optional cook note
- One-to-five-star rating
- Date and planned servings saved
- Cook history attached to recipes

## Kitchen Analytics
- Meals cooked
- Meals cooked this month
- Average rating
- Average serves
- Most-cooked recipes
- Recent cooking history

## Shopping Polish
- Manual shopping items can be deleted individually
- Generated items remain controlled by Generate/Reset
- Countable ingredients round up sensibly
- Tablespoons round to whole amounts
- Teaspoons round to halves
- Cups round to quarters
- Zero-item shopping cards show Complete

## Installation
1. Run `MFK_V1.2_Kitchen_Assistant.sql` in Supabase.
2. Upload and replace:
   - index.html
   - styles.css
   - app.js
   - sw.js
   - manifest.webmanifest
3. Keep the existing `config.js`.
4. Hard refresh or fully close and reopen the installed app.
