MFK v1.3.0 RC2 — COOKING INTELLIGENCE

WHY RC2 EXISTS

RC1 correctly deleted the Supabase active cooking session after Finish or Stop.
However, the Cooking Session card's CSS used `display: flex`, which overrode the
browser's built-in styling for the HTML `hidden` attribute.

The card therefore remained visible even though there was no session left to resume.
