SETUP

1. Use your existing MFK-V2-Workshop repository, or create a new MFK-V2 repository.
2. Extract this ZIP.
3. Copy the working config.js from your live V1 cookbook.
   Do not upload config.example.js as config.js unless you have inserted the real values.
4. Upload these files at the repository root:
   - index.html
   - styles.css
   - app.js
   - config.js
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
5. GitHub Pages:
   Settings → Pages → Deploy from branch → main → /(root)
6. Wait for deployment and open the site.
7. Sign in and test the five navigation tabs.
